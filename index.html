    .EXE 프로그램 만들기 (Electron 가이드)

    이 웹앱을 윈도우 실행 파일(.exe)이나 맥 앱(.app)으로 패키징하는 방법입니다.

    1단계: 폴더 만들고 파일 배치하기

    새 폴더를 만들고 index.html로 저장합니다.

    2단계: main.js 및 package.json 생성

    같은 폴더에 아래 코드로 main.js 파일을 만듭니다:

    const { app, BrowserWindow } = require('electron');

function createWindow () {
  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: { nodeIntegration: true }
  });
  win.loadFile('index.html');
}

app.whenReady().then(createWindow);

    3단계: 패키징 명령 실행

    npm init -y
npm install --save-dev electron electron-packager
npx electron-packager . MyCalendarApp --platform=win32 --arch=x64
